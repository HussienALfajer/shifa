# Shifa (شفاء)

Multi-tenant clinic management platform and patient app for private clinics in Syria (Aleppo and Azaz).

- **Clinic system:** appointments and walk-in queue in one engine, waiting-room screen with Arabic voice calling, medical records with full dental and orthopedic modules, DICOM imaging, and cash billing in three currencies (new Syrian pound, Turkish lira, US dollar) — Arabic-first, offline-tolerant.
- **Patient app (Flutter, Android first):** booking or taking a queue number, live queue position, family profiles, records released by the clinic.
- **Platform:** one model for solo doctors, multi-doctor clinics and multi-branch groups, with per-clinic features and settings managed by a super admin.

**Status:** documentation phase — no code yet. See [docs/roadmap.md](docs/roadmap.md).
