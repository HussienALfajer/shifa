# Local backup stack

PostgreSQL 18 archiving WAL with pgBackRest into an encrypted repository on a single-node Garage behind Caddy's TLS (spec 0.2-09c, PLT-51). Development and CI only, synthetic data. How to run it, restore to a time and read the drill report: [docs/process/backup-restore.md](../../docs/process/backup-restore.md).

| File | Purpose |
|---|---|
| `compose.yml` | Services `postgres`, `garage`, `garage-tls`; images pinned by version and digest |
| `postgres/Dockerfile` | PostgreSQL 18 (harness digest) with pgBackRest pinned exactly |
| `pgbackrest/pgbackrest.conf` | Repository, encryption, compression, retention; no secrets |
| `garage/garage.toml` | Single node; RPC secret and admin token come from the environment |
| `caddy/Caddyfile` | TLS (`tls internal`) in front of Garage's S3 API |
| `schedule.json` | Backup schedule and retention, the one source |
| `.env` | Generated by `pnpm backup:up`; git-ignored; never commit or share it |
| `.state/ca.crt` | The TLS root certificate copied by `pnpm backup:up`; git-ignored |

Only PostgreSQL is published: `127.0.0.1:55432`.
