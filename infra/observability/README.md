# Local observability stack

Development only: OpenTelemetry Collector, `grafana/otel-lgtm` (Grafana, Loki, Tempo, Prometheus) and GlitchTip with its PostgreSQL and Valkey, all bound to `127.0.0.1`. How to run it, where to look and the scrubbing rules: [docs/process/observability.md](../../docs/process/observability.md).

| File | Purpose |
|---|---|
| `compose.yml` | The services, pinned by version and digest |
| `collector.yaml` | Receivers, PLT-52 layer-two scrubbing (`resource/deny`, `attributes/deny`, `redaction`), export to otel-lgtm |
| `grafana/provisioning/` | Datasources (fixed uids) and the dashboard provider |
| `grafana/dashboards/shifa-api.json` | Starter dashboard |
| `.env` | Generated by `pnpm obs:up`; git-ignored; never commit or share it |

| Host port | Service |
|---|---|
| 4317, 4318 | Collector OTLP (gRPC, HTTP) |
| 3300 | Grafana |
| 3200, 3100, 9090 | Tempo, Loki, Prometheus query APIs (smoke check) |
| 8000 | GlitchTip |
