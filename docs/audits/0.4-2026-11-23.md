## Findings

### Blocking (fix slice 0.4-10)

Disposition: fixed by [slice 0.4-10](../slices/0.4-10-audit-fixes.md) (2026-11-23), each with a test: F1 `scripts/test/shifa-ui-goldens-skip.test.mjs`, F2 `scripts/test/no-real-phones.test.mjs`, F3 `scripts/test/design-directions.test.mjs`, F4 `scripts/test/claude-hooks.test.mjs`. The F2 scan also found an unmarked number in `spikes/s5-whatsapp/messaging/test/review-fixes.test.ts`; it is a planted case there, now joined at run time.

| ID | Finding | Evidence | Fix |
|---|---|---|---|
| F1 | `pnpm verify` fails on Windows, the documented unsandboxed fallback. The `shifa_ui` golden files register a test with an empty variant, because platform and CI goldens are both off outside Linux. | `.verify/logs/typecheck-lint-test.log`: `button_golden_test.dart` and `card_chip_golden_test.dart` fail with `'variant.values.isNotEmpty'` (`flutter_test_config.dart` enables CI goldens only on Linux) | Skip the golden tests, with a reason, when neither config is on (`shifaGoldenTest`), so Windows runs them through `node scripts/goldens.mjs` (Docker) as the config comment says; add a script test |
| F2 | Real-format Syrian phone numbers are typed in by hand and shown in public screenshots and design-system previews. This breaks `.claude/rules/patient-data.md` (generator only) and the generator's `00` marker. | `packages/ui/src/data-table/data-table.stories.tsx:33` makes eight `+963 9xx` numbers, visible in `components-datatable--patient-list.png`. `0944 123 456` appears in `drawer.stories.tsx:52`, `form.test.tsx`, three design-system `preview.html` files and two `shifa_ui` tests | A `phones()` fixture from `generatePhone`; replace each number; a repo scan test that fails on any full SY/TR mobile-shaped number that `isSyntheticPhone` rejects; refresh the baselines |
| F3 | The design-direction builds ship modified (subsetted) IBM Plex fonts under the reserved name "IBM Plex Sans Arabic", which OFL condition 3 forbids and OD-59 fixed for the product only. The repository is public. | `design/directions/*/fonts/ibm-plex-sans-arabic-*.woff2`: name table `IBM Plex Sans Arabic` / `IBMPlexSansArabic-Regular` (read with fontkit). `scripts/design-directions-build.mjs:41,62` writes the old family name | Use `webFamily` in the build and its sources, rebuild the four directions with the renamed subsets, and test that no woff2 under `design/` carries "Plex". This closes the backlog item "direction prototypes still carry the upstream-named Plex subsets" |
| F4 | The shell guard against fetch-and-run, the ADR-0041 threat, is bypassed by `pnpx`, `pnpm exec npx -y …`, `yarn exec` and `corepack npm install`. | `.claude/hooks/lib/policy.mjs:166,199-203`: `fetchesAndRuns` knows `bunx`, `npm exec`, `dlx` and `npx`, not `pnpx`, and the wrapper list does not re-check the word after `exec` or `corepack` | Treat `pnpx` like `bunx`; re-check the command after `pnpm exec`, `pnpm x`, `yarn exec`, `bun x` and `corepack`; add the four cases to `scripts/test/claude-hooks.test.mjs` |

F4 was rated non-blocking by its reviewer. It is in the fix slice because it is the guard this phase added, the fix is small, and the gap lets code outside the lockfile run on a machine where `.env*` files are readable (ADR-0028).
