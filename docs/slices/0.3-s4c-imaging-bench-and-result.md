## Findings from 0.3-S4b the report must carry
- C-STORE rewrites the DICOM file meta group (group 0002); the dataset after it arrives byte for byte. Edge-path checks compare datasets against the source and files against the edge copy (owner decision, 2026-11-16).
- The Transfers plugin (1.7) has no `/transfers/info`; a push is `POST /transfers/push`, `PUT /transfers/push/{id}/{n}`, `POST …/commit` (`DELETE …/{id}` on failure). The edge credential lives up to 12 hours, as Orthanc's peer header is fixed at start.
- The OHIF release image is built for the origin root (webpack public path `/`); the gateway proxies OHIF's `/viewer` route and a strict pattern of its static files at the root, cookie-gated, instead of a `/viewer/` prefix.
- The viewer cookie is `Secure`; inside the spike the gateway is plain HTTP, so the test browser marks the gateway origin trustworthy (`--unsafely-treat-insecure-origin-as-secure`). Production serves TLS.
- Bulk data URIs are off in OHIF (frames only): the gateway does not expose `/bulk/`, and Orthanc's BulkDataURIs name its internal host.
