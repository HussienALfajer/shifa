# 0.4-09 Icon set: Tabler Icons outline

Status: Built (PR open) · Tier: T1 · Branch: `feat/0.4-09-tabler-icons`
Spec: [0.4 Design system foundations](../specs/design-system/0.4-design-system-foundations.md) criterion 13 · Requirements: none · Decisions: OD-65 (owner, 2026-11-23), ADR-0040

After [0.4-08](0.4-08-flutter-theme-and-widgets.md). The owner's comparison of 28 icons (Phosphor Light and Regular, Tabler, Lucide, Iconoir, all outline) is the approved sheet for the look (ADR-0040); components change only in their icons.

## Goal
Every icon Shifa draws (web components, Storybook, the Shifa Design System, the Flutter widgets) is a Tabler outline glyph in one ink: near-black in light, light in dark, no second tone.

## Choices made by this plan
- **`@tabler/icons-react` 3.52.0** (MIT, exact pin, published 2026-11-14, past the 24-hour rule), replacing `@phosphor-icons/react`. The React package gives typed components that tree-shake, draw `stroke="currentColor"` with no fill, and render server-side for the design-system producer, as Phosphor did; the SVG package would need `?raw` imports per file and our own markup parsing.
- **Medical glyphs from Tabler** under the same keys: `tooth` → `IconDental`, `stethoscope` → `IconStethoscope`, `syringe` → `IconVaccine`, `medicines` → `IconPill`, `blood-drop` → `IconDroplet`, `heart-organ` → `IconHeartbeat`. Tabler has all six, so Healthicons leaves the repository (`src/icons/health/`, the `healthicons` dev dependency). `HEALTH_ICONS` stays exported as the medical group.
- **Carets become chevrons** (`IconChevron*`): Tabler's carets are small triangles; Phosphor's carets were chevron-shaped, so chevrons keep the look callers expect.
- **Stroke 2 on the 24 grid** (Tabler's default, as compared by the owner); round caps and joins.
- **Ink:** `color.icon.default` aliases the text colour (`ink.900` `#1d2a26` light, `ink.100` dark). `color.icon.muted` takes the same values: the done criterion is "every icon black in light", and the grey-green `ink.500` is what the owner disliked. The muted slot stays so callers do not change; a quieter icon later is a new owner decision. `color.icon-tone.*` (mint, gold) are unused and retired, with their schema exemption.
- **Flutter:** `ShifaGlyph` keeps its hand-drawn painters (no SVG parser in `lib/`, no new pub dependency), redrawn after Tabler on a 24 grid with a 2-wide round stroke; the nine glyphs keep their names. Goldens are refreshed with `node scripts/goldens.mjs --update` (Docker).
