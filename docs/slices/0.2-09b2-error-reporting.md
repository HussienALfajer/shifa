# 0.2-09b2 Error reporting to GlitchTip, scrubbed events, test-only failing route

Status: Planned · Tier: T0 · Branch: `feat/0.2-09b2-error-reporting`

Depends on: 0.2-09b1 merged (bootstrap, `env.ts`, leak test). Blocks: 0.2-09b3 (smoke check needs the failing route and events).

## Goal
Unhandled exceptions and 5xx responses reach GlitchTip through the Sentry SDK with route template, status, `requestId`, `trace_id` and release, and nothing else; 4xx are never sent; with `SENTRY_DSN` unset the SDK is not initialised.

## Plan
1. **Contracts / database / web / Flutter.** None. The error envelope is unchanged.
2. **Config** (`config/env.ts`): `SENTRY_DSN` (optional URL), `SENTRY_RELEASE` (optional, default `service.version`); `.env.example` gains a local `127.0.0.1` placeholder.
3. **SDK** (`src/telemetry/errors.ts`, initialised from `instrument.ts`): use the Sentry package that does not install its own OpenTelemetry setup (`@sentry/node-core`, or `@sentry/node` with `skipOpenTelemetrySetup: true`), so 0.2-09b1's tracer provider stays the only one; no tracing (`tracesSampleRate` unset), `sendDefaultPii: false`, default integrations off except the ones needed for stack frames and uncaught/unhandled capture; no request-data, local-variables, console or http breadcrumbs integrations.
   - `beforeSend` rebuilds the event from an allowlist: exception type, stack frames (`filename`, `function`, `lineno`, `colno`; no `vars`, no `context_line` source text), tags `route`, `status`, `request_id`, `trace_id`, `release`, `environment`. Exception `value` is replaced by `describeError` type and code (SQLSTATE for database errors). `beforeBreadcrumb` returns null. `request`, `user`, `extra`, `contexts` other than `trace` are dropped.
4. **API** (`platform/errors.ts`, `main.ts`): `GlobalExceptionFilter` captures when `status >= 500` with the route template and ids; HttpException 5xx with a cause captures the cause class; 4xx never. `crash()` in `main.ts` captures and `flush(2000)` before exit.
5. **Test-only failing route**: `GET /v1/_test/fail` in a `TestSupportModule` registered only when `NODE_ENV === 'test'`; throws an error whose message quotes a synthetic value. Excluded from the OpenAPI document (generator and drift run without it); the route matrix gets a `testOnly` marker and the expected matrix lists it; `/add-endpoint` steps followed.
