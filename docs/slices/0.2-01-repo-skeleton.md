## Goal
Every later slice starts from a repository where one command (`pnpm verify`) formats, typechecks, lints and tests what changed, and `main` only changes through reviewed pull requests.

## Plan
1. GitHub: protect `main` (PR required, linear history, no force push or deletion, admins included, conversations resolved), squash-only merges, delete merged branches. Done through the GitHub API on 2026-11-08; secret scanning and push protection were already on.
2. Workspace: pnpm 12 workspaces (`apps/*`, `packages/*`, `tooling/*`), `minimumReleaseAge` 24 h, Turborepo tasks `typecheck`, `lint`, `test` with caching.
3. Tooling packages: `@shifa/tsconfig` (strict base, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`), `@shifa/eslint-config` (typescript-eslint strict + stylistic type-checked, `no-floating-promises`, `max-lines` 400).
4. Formatting: Biome formatter only (LF, single quotes); ESLint does the linting.
5. `scripts/verify.mjs`: `fast` (Turborepo `--affected` against `main`) and `full`; short PASS/FAIL summary, logs in `.verify/logs/`, lock file so only one run at a time.
6. `scripts/check-instruction-size.mjs`: byte budgets from [development-workflow §8](../process/development-workflow.md).
7. First package `@shifa/testing` with `FixedClock` so the toolchain is proven end to end.

Tests written first: `packages/testing/test/clock.test.ts`.
