# 0.4-02 Three design directions, the owner's choice, and fonts

Status: Planned · Tier: T1 (sets the token values every component reads; synthetic names only) · Branch: `feat/0.4-02-design-directions`
Spec: [0.4 Design system foundations](../specs/design-system/0.4-design-system-foundations.md) criteria 4–5 · Requirements: none · Decisions: ADR-0039, OD-57, OD-56, OD-20

After [0.4-01](0.4-01-tokens-pipeline-and-contrast.md). Four checkpoints (A–D); B and C need the owner.

## Goal
The owner has opened three interactive design directions on the same three screens, picked one, and the choice is recorded: its rationale in the design doc and its values (type scale, radius, elevation, motion, icon style) in the tokens. The two font families are self-hosted, subsetted and licensed in the repository.

## Choices made by this plan
- **Where the builds live:** `design/directions/<a|b|c>/` at the repository root, each a static build exported from Claude Design (HTML, CSS, JS, no network at run time), marked `linguist-generated` and excluded from Biome, ESLint and the file-length check. `design/directions/README.md` says how to open them and which one was chosen. The two not chosen stay as the record of the decision.
- **Who makes them:** the session writes one brief per direction (`design/directions/briefs/<id>.md`: the seven principles, the palette, the three screens, synthetic data from `@shifa/testing`); the directions are produced in Claude Design with the owner, exported, and committed by the session.
- **Screens (same in each):** reception queue (desktop), doctor visit (desktop and 10-inch tablet), patient booking (phone); each with RTL, a light/dark switch, a density switch and both digit styles (OD-20).
- **Fonts:** source files in `packages/tokens/fonts/`: WOFF2 subsets for the web (Arabic, Latin, digits, punctuation) and TTF for Flutter, with `OFL.txt` per family and a `fonts.json` manifest (family, weights, version, source URL, SHA-256). Subsetting by a pinned tool run through `scripts/`; outputs committed.
- **Budget:** each WOFF2 subset ≤ 60 KB; the test holds the number.

## Plan
