## Goal
The Shifa design project exists in Claude with a design system filled from the repository: tokens from a generated, drift-checked output of `packages/tokens`, fonts, logo and icons; and one guide page drawn from them. The values the Warm direction still owes are in the tokens.

## Choices carried over from the 0.4-02 plan
- **Design-system token output:** a fourth output of the tokens build, `packages/tokens/generated/design-system/tokens.json`, in the Design System type's list format (colours per theme with usage notes, type styles, spacing, radius, shadows), under the `tokens` drift check. Usage notes come from `$description`; a semantic token without one fails the schema test.
- **Values to fill** (Warm direction, design doc "Design language"): named type styles (title, label, paragraph), the focus ring as an elevation, icon and disabled-text colours, the overlay colour, a selection tint scale, an avatar palette, the icon set (Phosphor duotone, Healthicons).
- **Guide page:** one artboard set in a "Shifa Guide" canvas drawn from the output above: the layer flow, then 01 Foundations, 02 Theme, 03 Tokens, 04 Effects, 05 Typography, 06 Rules.
- **Design system:** filled (brand book, tokens, fonts from `packages/tokens/fonts/`, logo, icons), marked as synced from code and set as the account default.
