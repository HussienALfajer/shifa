## Goal
The owner opens one static page, enters a participant code, and the build walks a dentist through tasks D1–D4 on the odontogram in Arabic, scores each attempt and exports the session log. The same bundle runs on the tablet by touch and makes no request outside its own origin.

## Choices made by this plan
- **Stack:** React 19 + Vite (the clinic web stack, ADR-0010), plain CSS with logical properties only, no router, no `packages/ui`, no tokens (both out of scope); Arabic strings in a local file (not `packages/i18n`). Vazirmatn (ADR-0034) is bundled as a local font file; nothing loads from a CDN.
- **Charts are not mirrored in RTL:** each chart sits in a `dir="ltr"` island with the patient's right on the viewer's left, and a fixed "يمين المريض / يسار المريض" caption; the page around it is `dir="rtl"`.
- **Tooth art is self-drawn:** eight SVG templates (incisor, canine, premolar, molar × upper, lower) with a buccal + root view and a five-surface occlusal view, kept in `web/src/assets/teeth/` with a `SOURCE.md`, written to be reused in Phase B.
- **State:** the reducer from `@shifa-spike/s8-rules`; the running session is kept in `localStorage` so a reload does not lose it, and is cleared when the log is exported (criterion 2: nothing stored after export; tested).
- **Moderator controls:** a small "مشرف" corner control (long-press on touch, `Ctrl+Shift+M` on the laptop) opens: mark attempt assisted, skip task, end session. It is outside the participant's task area and never needed to finish a task.
- **Two devices, one file per participant:** each device exports `<code>-<device>.json`; the report script in 0.3-S8d merges them into one file per participant. The tablet file is moved to the laptop by cable (the moderator script says how).
- **Statuses:** the seven seed items use the fixed colours of DEN-07 for "existing", "planned" and "condition"; the other statuses are not shown.
- **Timing:** duration runs from the moment the task text is dismissed to "انتهيت"; the two minutes of free exploration are a separate untimed screen.

- `.github/workflows/s8-charts.yml`: `workflow_dispatch` only, `permissions: {}`, actions pinned by SHA like `s3-arabic-output.yml`; jobs `rules` (Vitest) and `e2e` (Playwright, screenshots uploaded); no secrets.
