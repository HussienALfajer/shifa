## Goal
The owner picks the Google voices in a pre-round, rates five anonymous voices blind in a static page and downloads a results JSON; a script joins it with a separate key and names the winner under the OD-50 rule. The display page from 0.3-S6a has run on an Android TV emulator in Fully Kiosk Browser (free) and the emulator's WebView. The report `docs/spikes/s6-voice.md` answers every spec question with versions, numbers, costs and quoted vendor terms; ADR-0037 records the provider, voice, fallback order, text normalisation and playback rules.

## Choices made by this plan

### Listening page and analysis
- **Static, no server:** a Vite-built page served from local files by `vite preview` on `127.0.0.1`; no backend, no request beyond its own origin.
- **Listening set builder:** `build-listening-set --manifests <files…> --seed <n>` copies the chosen voices' clips into `.out/listening/clips/<code>.<ext>` under random codes (8 base32 chars from a CSPRNG), writes `listening-set.json` for the page (codes, category, text shown only for numbers and names, announcement code lists) and `listening-key.json` (code → provider, voice, clipId) outside the served folder. It refuses manifests with any `failed` clip.
- **What the owner sees:** for numbers and names the intended text (so "correct / wrong" can be judged); never provider, voice, file name or a duration hint. Random order per seed, voices interleaved so the same text is not heard back to back.
- **Pairs:** the page samples 20 pairs from the 10 announcements × 10 voice pairs (each announcement twice, each voice pair at least twice, fixed by the seed) and plays each side by joining clips with Web Audio. Choice: A / B / same.
- **Progress:** `localStorage` keyed by the listening-set hash, saved on every change; "reset" asks twice. Results JSON: set hash, codes, scores, wrong flags, notes, pair choices, timestamps; no listener identity.
- **Pre-round mode (criterion 2):** `?mode=pre-round` shows 6 Chirp 3 HD voices × 5 phrases under neutral labels (صوت ١ … صوت ٦); the owner picks one male and one female; the page downloads `pre-round-choice.json`.
- **Decision rule (OD-50), in code:** among voices with no wrong number, the highest mean naturalness wins; a tie (difference < 0.05) goes to fewer wrong names; if every voice has a wrong number, the script says "no eligible winner" and lists the wrong numbers for a corrected-text regeneration the owner confirms. Means with n and sd; no significance claim from one listener.
- **Arabic UI:** RTL, Arabic labels, keys 1–5 for score, ص/خ for correct/wrong, space to replay.

### Owner's run
- **Checklist:** `docs/spikes/s6-manual-checklist.md` (like the S5 one): keys into `.env.local`, SILMA build, pre-round, generation, listening, emulator; each step with the command and what to send back.
- **Generation order:** dry-run counts shown to the owner first; pre-round (Google 6 × 5 only); pick recorded; full set for Azure ×2, Google ×2, SILMA ×1; manifests committed under `spikes/s6-voice/manifests/`; audio stays untracked.
- **Key file:** committed only after the analysis, so the blind test is not exposed before it ends.
- **Emulator (criterion 9):** Android Studio's Android TV system image (API level and image version recorded) on the owner's machine with `adb`; the page served by `vite preview --host` and reached at `10.0.2.2`. Fully Kiosk Browser free APK downloaded only from fully-kiosk.com and only after the owner's yes at that step (name, version, size and SHA-256 in the ask); the emulator's own WebView/browser where present. Per runtime: autoplay without a tap; cache surviving an emulator restart with the network off; Wake Lock past the display timeout; gapless joins measured by recording the emulator audio output (host loopback capture or `adb` recording, whichever works is recorded) and running `scripts/measure-gaps.ts`; first-call latency after reload.
- **Pack size and cost (criterion 10):** `scripts/pack-size.ts` encodes each voice's clips with a pinned `ffmpeg` image (by digest) to Opus 24/32 kbps and MP3 48/64 kbps and extrapolates to a full 1–999 + rooms pack from per-category means (no full pack generated). Characters billed from the manifests; monthly estimate per clinic from the pack (once per voice), rooms (once per clinic) and name clips at a stated new-patient rate; free-tier headroom shown. SILMA timing on CPU, and GPU if present.
- **Vendor terms (criterion 11):** short quotes (under 15 words each) of the relevant clauses of Azure, Google Cloud and the SILMA licence (sanctioned territories, export control, rights in generated audio), with link and access date, and what they mean for audio generated outside Syria and served to devices in Syria (VOX-10); information for the owner, not legal advice.
- **ADR-0037** "Voice calling: TTS vendor, voice and kiosk playback": Proposed, Accepted on the owner's approval; ADR-0020 changes only its `Status:` line (`· Amended by ADR-0037`).

## Stopped at
Checkpoints A–B built and green (2026-11-18); the owner's checklist is written. Next: checkpoint C step C1 (vendor resources and keys) in `docs/spikes/s6-manual-checklist.md`.

Changes from the plan made while building A–B:
- Served folder: the builder writes `<out>/served/{listening-set.json, pre-round-set.json, clips/}` and the keys to `<out>/` (default `.out/listening/`); the page's Vite `publicDir` is that `served/` folder (`--mode test`: the fake set in `listening/test-set/`).
- Pair clips get their own codes (not the rating codes), so a code seen in a pair cannot be matched to a rated clip.
- A clip must be heard before it can be scored (the page plays it on show); pair choices need no replay.
- The emulator reaches the host as `localhost` through `adb reverse` (a service worker and Wake Lock need a secure context; `http://10.0.2.2` is not one).
- `display/scripts/make-pack.ts` builds the real voice pack for the emulator (`?pack=voice`).
- `check-no-keys`: the generic pattern no longer matches a value that continues into a member access or call (`key = listeningKeySchema.parse(`); keys at a sentence end still match.
- Locked test `listening-set.test.ts` contradicted itself (`clips/<code>.wav` required, `.wav"` forbidden); fixed with the owner's approval (2026-11-18) to forbid the source file names instead.
- Biome skips `analysis/test/__snapshots__/`, `manifests/` and `results/`, so the committed analysis stays byte-identical to the script's output.
