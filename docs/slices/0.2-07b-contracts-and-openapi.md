Depends on: 0.2-07a (drift runner). 0.2-07c and 0.2-07d build on this slice.

## Goal
`packages/contracts` holds named Zod 4 schemas, the error envelope and the central error-code catalogue. Every API route declares its contract; the API validates requests with it and refuses to start if a route has none. An OpenAPI 3.1 document is generated from the routes and contracts, committed, and checked for drift in CI.

## Plan
1. **Contracts** (`packages/contracts`, new workspace package, exports `.ts`):
   - `errors.ts`: `ErrorCode` string enum (the codes now in `apps/api/src/platform/errors.ts`), `ErrorEnvelope` schema, status → code table. `apps/api` imports these; `KNOWN` moves here.
   - `health.ts`: `HealthStatus`. Every exported schema carries `.meta({ id })`; ids are PascalCase and unique.
   - `define.ts`: `defineContract({ method, path, request: { params?, query?, body? }, responses: { [status]: schema } })` returning a typed object.
   - Validation-error detail for 400s (e.g. `details: [{ path, code }]`, never input values) is a contract decision: **confirm with the owner before building**; until then 400 stays the plain envelope.
2. **Database.** None.
3. **API** (`apps/api/src/platform/contract/`):
   - `@Contract(c)` handler decorator; a pipe/interceptor validates params, query and body with Zod and answers 400 with the envelope (no echo of input; logs carry route template and issue codes only). Prefer Nest 12's Standard Schema support if the pinned 12.4.0 has it; otherwise a small pipe. Record the choice in the PR.
   - Start-up check (next to `access-check.ts`): a handler without `@Contract`, or whose method/path differ from the route Nest registered, refuses start (one error listing every handler).
   - `openapi.ts`: builds the OpenAPI 3.1 document from `DiscoveryService` routes + contracts with Zod 4 `z.toJSONSchema` (named schemas → `components/schemas`, `$ref` everywhere, no inline anonymous objects); adds the security note per route from `@Public`/`@RequirePermission` (`x-permission`). No `@nestjs/swagger`, no Swagger UI route (keeps backlog item "raw routes outside the guard" from growing).
   - `scripts/generate-openapi.ts`: builds the app with a stub DB (no connection) and writes `packages/contracts/generated/openapi.json` (sorted keys, stable output). Registered with the drift runner as `openapi`.
   - Health controller gets its contract.
4. **Lint.** A test in `packages/contracts` fails for any exported Zod schema without an id, and for any anonymous object/enum reaching the generated document (ADR-0013 "lint on unnamed schemas").
5. **Web / Flutter.** None (clients are 0.2-07c).
6. **Instructions.** `packages/contracts/CLAUDE.md` (naming, nullability rules: required vs `.nullable()` vs `.optional()`, string enums only); `/add-endpoint` step "contract stub" becomes "write the contract in `packages/contracts`, run `check-drift --fix`"; `.claude/rules/api.md` names `@Contract`.
