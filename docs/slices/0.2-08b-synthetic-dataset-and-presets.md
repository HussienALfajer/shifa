# 0.2-08b Synthetic dataset: tenancy model, presets and integrity checks

Status: Planned · Tier: T1 · Branch: `chore/0.2-08b-synthetic-dataset`
Spec: [0.2-08](../specs/foundation/0.2-08-synthetic-data-generator.md) (criteria 1–6, 8, 11, 12, 13, 14; edge cases) · Requirements: PLT-50, CLN-38, PLT-01 to PLT-07, BIL-02 to BIL-04
Depends on: 0.2-08a merged (random, ids, names, phones, money). Last slice of the spec.

## Goal
`generateDataset({ seed, preset, clock?, load? })` returns typed, in-memory records for several Aleppo and Azaz clinics that follow the tenancy model, are the same for the same seed on every machine, and carry the name, phone and family edge cases later slices need.

## Plan
1. **Contracts / database / API / web / Flutter.** None. Record types are local to `@shifa/testing` (`Synthetic*` names) because no domain schemas exist yet; each Phase A slice that adds a table maps them into its insert helper.
2. **Package** `packages/testing/src/synthetic/`:
   - `model.ts`: `SyntheticTenant` (id, name, kind `solo | multi-doctor | multi-branch`, city, `baseCurrency: 'USD'`), `SyntheticOrganization` (tenantId), `SyntheticBranch` (tenantId, organizationId, city, `enabledCurrencies`, `priceList: { code, price: Money }[]`), `SyntheticResource` (tenantId, branchId, kind room/chair), `SyntheticPractitioner` (global: id, name, sex, phone), `SyntheticPractitionerRole` (tenantId, practitionerId, organizationId, branchId), `SyntheticPatientAccount` (global: id, phone, holder name, birthDate), `SyntheticDependent` (accountId, name, birthDate, relation), `SyntheticChart` (tenantId, organizationId, accountId, dependentId?, mrn), `SyntheticDataset` (arrays of each, plus `seed`, `preset`, `generatedAt`).
   - `clinic-names.ts`: name patterns ("مركز {family} لطب الأسنان", "عيادة د. {given} {family}", "مجمع … الطبي"), never a real clinic.
   - `build-tenant.ts`: one tenant from a `TenantPlan` (kind, city, branch count, practitioner count, patient count) using `random.fork(tenantIndex)`; city decides currencies (Aleppo SYP+USD; Azaz TRY+USD, some also SYP) and phone mix (Aleppo mostly `+963`, Azaz mixed); MRN per organization from a counter; birth dates from the clock (child / adult / 65+ buckets); dependents under 18 under an adult account, some accounts with two or more dependents on one phone.
   - `presets.ts`: `minimal` (2 solo tenants, one in each city, ≥ 5 patients each, places the `NAME_VARIANT_SAMPLES` and duplicate pair), `demo` (≥ 4 tenants: solo, multi-doctor, multi-branch, Aleppo and Azaz; one practitioner with roles in two tenants; variant names and duplicate pair), `load` (`{ tenants = 50, patientsPerTenant = 1000 }`, rejects 0 and above 10 000 tenants / 1 000 000 patients with `InvalidPresetParamsError`).
   - `generate-dataset.ts`: validates input, builds tenants, adds cross-tenant roles, registers every id in the `IdRegistry`; default clock `new FixedClock('2026-01-01T00:00:00Z')`.
   - `canonical-json.ts`: stable key order, bigint as `"<n>n"` string, for the golden hash and for later JSON dumps.
3. **Instructions.** Extend `packages/testing/CLAUDE.md` with "how to add a record type" (new `fork` label, integrity walker entry, golden hash update in the same PR with reason).
