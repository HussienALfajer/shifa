# 0.4-09 Icon set: Solar Broken

Status: Built (PR open; re-planned 2026-11-23) · Tier: T1 · Branch: `feat/0.4-09-tabler-icons` (name kept: PR 113 is open on it; the file was renamed from `0.4-09-tabler-icons.md`)
Spec: [0.4 Design system foundations](../specs/design-system/0.4-design-system-foundations.md) criterion 13 · Requirements: none · Decisions: OD-65 (owner, 2026-11-23, amended the same day), ADR-0040

After [0.4-08](0.4-08-flutter-theme-and-widgets.md). The slice was first built with Tabler Icons. The owner then compared our 28 icons side by side in Tabler, Solar Linear and Solar Broken (light, dark, inside buttons and a search field at 20 px). They chose **Solar Broken**, after being told it is the least legible of the three at small sizes. That comparison is the approved sheet for the look (ADR-0040); components change only in their icons.

## Goal
Every icon Shifa draws (web components, Storybook, the Shifa Design System, the Flutter widgets) is a Solar Broken glyph: outline with deliberately gapped strokes, one tone, near-black in light and light in dark. The tooth is the one exception: Solar has none, so it stays the Healthicons outline.

## Kept from the Tabler build
- The tokens: `color.icon.*` is the text colour and `color.icon-tone.*` is retired.
- The disabled-control fix: icons inherit the control's colour (`icon-ink.test.tsx`).
- The `Icon` API, the `IconName` keys and the directional list, so no caller changes.
- The producer's Icons group, the stories and the docs structure.

## Choices made by this plan
- **Distribution: vendored SVG files, generated from `@iconify-json/solar` 1.2.17.**
  - The package is CC BY 4.0, an exact dev dependency, published 2026-11-21, so it passes the 24-hour rule.
  - `scripts/icons-sync.ts` writes the SVG sources (Solar's, and the Healthicons tooth) as one plain module, `src/icons/generated/icons.ts`, from the package. A node test fails when it differs from what the script would write. A plain module rather than SVG files read with Vite's `import.meta.glob` or `?raw` (the first build, changed after review): any bundler loads it, including the planned Next.js booking site.
  - Why vendored rather than imported at runtime: the package is one 13 MB JSON with 9,729 icons. Imported, it would reach every bundle. Vendored, only our 41 glyphs ship, the design-system producer and Flutter use the same sources, and the attribution sits beside them (`src/icons/solar/LICENSE.md`).
  - `@tabler/icons-react` leaves.
- **Mapping** (Solar names, all `-broken`).
  - The owner's sheet: `calendar-plus` calendar-add, `calendar` calendar, `clock` clock-circle, `printer` printer-minimalistic, `pencil` pen-2, `trash` trash-bin-minimalistic, `magnifying-glass` magnifier, `user` user-rounded, `users` users-group-rounded, `phone` phone, `bell` bell, `info` info-circle, `warning` danger-triangle, `check-circle` check-circle, `cloud-check` cloud-check, `wifi-slash` cloud-cross (the sheet's offline glyph; Solar also has wi-fi-off, not used), `arrow-forward` arrow-right, `caret-forward` alt-arrow-right, `sign-out` logout-2, `stethoscope` stethoscope, `syringe` syringe, `medicines` pill, `blood-drop` waterdrop, `heart-organ` heart-pulse.
  - The rest of the list: `arrow-back` arrow-left, the other carets alt-arrow-left, -up and -down, `dots` menu-dots, `eye` eye, `eye-slash` eye-closed, `file-text` document-text, `gear` settings, `house` home, `list` hamburger-menu, `x-circle` close-circle.
  - Control glyphs stay plain: `check` check, `x` close, `plus` add, `minus` minus. The sheet's check-read (a double tick) and add-circle would read oddly in a checkbox tick, a dialog close and a stepper whose minus is plain. The circled forms stay available as `check-circle` and `x-circle`.
- **`sign-out` is mirrored when vendored.** Solar's logout-2 points to the start in LTR, while our directional rule draws "forward" glyphs pointing to the end and mirrors them in RTL. The file wraps the glyph in a horizontal flip, and the licence note records this change (CC BY 4.0 asks for changes to be indicated).
- **Stroke** is Solar's own: 1.5 on the 24 grid, round caps, and round joins where Solar sets them.
- **Flutter: no new dependency.** The same script turns the nine base-widget glyphs into Dart `Path` code in `shifa_ui/lib/src/generated/glyphs.g.dart`. Solar uses only `path` and `circle` with absolute `M L H V C Z` commands. The output is drift-checked by the same test, and painting stays synchronous, so the goldens stay stable. `flutter_svg` would add `vector_graphics` and asynchronous loading to a package that is widgets-layer only.
  - The Flutter glyphs: `check`, `close`, `alt-arrow-right`, `arrow-left`, `calendar`, `bell`, `menu-dots-vertical` (more), `danger-circle` (error), `check-circle`.
- **Attribution:** `src/icons/solar/LICENSE.md` names the author (480 Design), the source, the licence and the changes. The design-system Icons note and the design doc credit it. The patient app's About screen must credit it too; no About screen exists yet, so this is a backlog item.
