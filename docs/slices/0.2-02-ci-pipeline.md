# 0.2-02 CI pipeline

Status: In review · Tier: T0 · Branch: `ci/0.2-02-ci-pipeline`
Spec: none (foundation tooling; scope is the Phase 0.2 checklist in [roadmap](../roadmap.md)) · Requirements: —

## Goal
No change reaches `main` unless CI has run the same `verify` as developers, scanned for secrets and vulnerable packages, linted the workflows and checked the PR size.

## Plan
1. `.github/workflows/ci.yml` on pull requests and pushes to `main`; `permissions: {}` at the top, read-only per job; `persist-credentials: false`; every action pinned to a full commit SHA.
   - `verify (full)`: `pnpm install --frozen-lockfile` (24-hour minimum package age applies) then `node scripts/verify.mjs full`; prints the logs on failure.
   - `dependency audit`: `pnpm audit --audit-level high`.
   - `secret scan (gitleaks)`: gitleaks 8.30.1 binary (SHA-256 checked) scans every commit of the PR (`base..head`) or of the push (`before..after`).
   - `workflow lint (zizmor)`: static analysis of the workflows themselves.
   - `PR size budget`: `scripts/check-pr-size.mjs`; warns above 1,000 hand-written lines, fails above 2,000 unless the owner adds `size/override`.
2. `scripts/lib/pr-size.mjs` (pure logic: `git diff -z --numstat -M`, renames counted by their edits only, `linguist-generated` read from the base branch) with `node:test` tests; `verify` gains a `scripts-test` step that fails when no tests are found.
3. `.github/dependabot.yml`: weekly grouped updates for the pinned actions, 7-day cooldown.
4. After the first green run: make the five job names required status checks on `main`.

Tests written first: `scripts/test/pr-size.test.mjs`.
Estimated hand-written lines: ~350.
