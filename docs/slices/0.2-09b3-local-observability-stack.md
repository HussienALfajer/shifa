# 0.2-09b3 Local observability stack: Collector, Grafana, GlitchTip, `obs:*` scripts, smoke check

Status: Planned · Tier: T0 (infrastructure, layer-two scrubbing) · Branch: `feat/0.2-09b3-local-observability-stack`
Spec: [0.2-09b](../specs/foundation/0.2-09b-observability-skeleton.md) (criteria 7, 8, 9, 10, 11) · Requirements: PLT-52 · Decisions: ADR-0029, ADR-0022 (proposed)
Depends on: 0.2-09b1 and 0.2-09b2 merged (the smoke check needs spans, logs and the failing route). Last slice of the spec. The compose and Collector files touch no API code, so they may be started in a parallel worktree while 0.2-09b2 is built; the smoke check and the PR come last.

## Goal
`pnpm obs:up` starts a local stack bound to `127.0.0.1`, `pnpm obs:smoke` proves a request's trace, log line, metric and error all arrive, and the Collector deletes denied keys again before storage.

## Plan
1. **Contracts / database / API / web / Flutter.** None in product code.
2. **Compose** `infra/observability/compose.yml`: `otel/opentelemetry-collector-contrib` (redaction and attributes processors live in contrib), `grafana/otel-lgtm` (Grafana, Loki, Tempo, Prometheus; its own OTLP ports stay on the compose network, not published), GlitchTip web + worker, PostgreSQL 18 and Valkey for GlitchTip. Every image `name:version@sha256:…`; every `ports` entry `127.0.0.1:…`; Grafana on `127.0.0.1:3300` (3000 is the API default); named volumes; healthchecks.
3. **Collector** `infra/observability/collector.yaml`: OTLP receiver on `127.0.0.1:4317/4318` (host side); processors `memory_limiter`, `attributes/deny` and `redaction` deleting the denied keys from the spec (bodies, `url.query`, `url.full`, cookies, `authorization`, client address, `db.query.text`/`db.statement`, `exception.message`), `transform` for log bodies is not used (logs are pre-sanitised in the API); `batch`; exporters to otel-lgtm.
4. **Grafana** `infra/observability/grafana/`: datasource provisioning and one dashboard JSON (request rate, error rate, p95 latency by route).
5. **Scripts** (Node ESM, `node:` built-ins, argument arrays, no shell): `scripts/obs.mjs up|down|reset|smoke` over a pure core `scripts/lib/obs.mjs`.
   - `up`: on first run writes `infra/observability/.env` (git-ignored by the root `.env` rule) with a random GlitchTip `SECRET_KEY`, admin password and DB password (`crypto.randomBytes`), never printed; `docker compose up -d --wait`; bootstraps GlitchTip once (superuser, organisation `shifa-local`, project `shifa-api`) through `manage.py` and stores the project DSN and an API token in the same `.env`. `down` stops; `reset` removes volumes and the `.env` after a confirmation flag (`--yes`).
   - `smoke`: starts PostgreSQL through `@shifa/db/harness` (as the boot check does), runs the built API with `--import ./dist/instrument.js`, `NODE_ENV=test`, the Collector endpoint and the DSN; calls `/health/ready` and `/v1/_test/fail`; polls for up to 60 s: Tempo (trace by id from the response's `traceparent`/log), Loki (a line with the same `trace_id`), Prometheus (`http_server_request_duration` series), GlitchTip API (one new event). Prints one line per check, exits 1 on any miss.
   - `package.json`: `obs:up`, `obs:down`, `obs:reset`, `obs:smoke`.
6. **Docs**: `docs/process/observability.md` (run, where to look, the two scrubbing layers, how to add an attribute safely: allowlist in `scrub.ts` + leak test string + Collector deny list review); link from `docs/README.md` and data handling §1; root `CLAUDE.md` Commands line for `obs:*`. CI secret scan already covers `infra/` (check the gitleaks config path list).

## Risks
- Image digests and the Collector run test need Docker, which the sandboxed WSL2 session cannot reach (OD-24): digests are looked up by the owner (`docker buildx imagetools inspect`) or in CI; the session writes the compose file with the values the owner pastes.
- GlitchTip bootstrap through `manage.py` may change between versions; pin the version and test the bootstrap in the smoke check.
- otel-lgtm is a development image; staging and production use separate components (OD-01, out of scope).
