# 0.3-S1e Flutter probe for the offline sync spike

Status: Planned · Tier: T0 (patient data on devices, encryption at rest) · Branch: `chore/0.3-s1e-flutter-probe`
Spec: [0.3-S1 offline sync](../specs/spikes/0.3-s1-offline-sync.md) criterion 11 · Requirements: PAT-08 · Split from [0.3-S1](0.3-s1-offline-sync-spike.md) checkpoint E: 0.3-S1 reached ~5,400 hand-written lines before E (budget ~4,000, [ADR-0032](../adr/0032-slice-size-budget-4000-lines.md)), and its plan named the Flutter probe as the piece to split out.

## Goal
A thin Flutter probe proves, on both engines, that a patient's cached appointments and ticket are readable in airplane mode, that the local store is encrypted with SQLCipher, that an offline cancellation syncs exactly once, and that logout deletes the store. Its results go into `docs/spikes/s1-offline-sync.md` (criterion 11 row) before ADR-0031 is accepted.

## Builds on (already merged with 0.3-S1)
- Spike server: `POST /auth/patient-login`, `GET /sync/pull` (patient tokens see their own rows only), `POST /commands` and `POST /powersync/upload` (patients may only `appointment.cancel` their own appointment).
- Scenario stack (`spikes/s1-offline/scenarios/harness/stack.ts`): PostgreSQL, server, PowerSync service and Toxiproxy; the probe's "airplane mode" is its proxy disabled. The `patient_appointments` sync stream exists in `scenarios/powersync/sync-config.yaml`.

## Plan
1. `spikes/s1-offline/flutter_probe/` (standalone Flutter package outside the pub workspace, own lockfile, pinned toolchain via `node scripts/dart.mjs flutter ...`, `very_good_analysis`): outbox engine on drift with SQLCipher; PowerSync engine on the Flutter SDK's SQLCipher variant, with the drift integration if usable on the pinned Flutter (record it). One screen: my appointments, my ticket, cancel, pending badge.
2. **Tests first** (`flutter test` on the desktop host, each engine): `cache_offline_test.dart` (sync, cut, restart → readable); `encryption_test.dart` (no key → open fails; no plaintext of a known synthetic value in the file; `PRAGMA cipher_version` set); `cancel_sync_test.dart` (offline cancel + retry → one cancellation on the server); `logout_test.dart` (database file deleted).
3. A small Node launcher starts the scenario stack for the probe and passes URLs and a patient id through `--dart-define`; the `s1-offline` workflow gains the `flutter` job (input `flutter: true`).
4. Report row for criterion 11 in `docs/spikes/s1-offline-sync.md`; reviewer + security-reviewer.

Risk: SQLCipher's native build on the desktop test host; if it fails in CI, run the encryption test on an Android emulator job and record it.
