# 0.2-08a Synthetic data primitives: seeded random, ids, names, phones, money

Status: Planned · Tier: T1 · Branch: `chore/0.2-08a-synthetic-primitives`
Spec: [0.2-08](../specs/foundation/0.2-08-synthetic-data-generator.md) (criteria 1, 2 partly, 7, 8 partly, 9, 10, 11 partly, edge case "seeds") · Requirements: PLT-50, CLN-38, MSG-32, BIL-01 to BIL-05
Depends on: nothing (`packages/testing` with `Clock`/`FixedClock` exists). Followed by 0.2-08b, which assembles the dataset from these parts.

## Goal
`@shifa/testing` exports the deterministic building blocks of the generator: a seeded random source, UUID-format ids, Syrian Arabic person names with every spelling variant class, synthetic +963/+90 mobile numbers with `isSyntheticPhone` and format regexes, and `Money` values in SYP/TRY/USD on cash units. Nothing reads the system time, the environment, the network or a database.

## Plan
1. **Contracts / database / API / web / Flutter.** None. No new runtime dependency (hand-written PRNG; `node:crypto` only in tests).
2. **Package** `packages/testing/src/synthetic/`:
   - `random.ts`: `createRandom(seed)` returning a seeded PRNG (sfc32 or mulberry32, seed hashed to state) with `int(min,max)`, `pick`, `weighted`, `shuffle`, `chance`, `fork(label)` (independent sub-stream, so adding a field later does not shift every other value). `InvalidSeedError` for non-integer, `NaN` or non-finite seeds; seed `0`, negative and `Number.MAX_SAFE_INTEGER` accepted.
   - `ids.ts`: `nextId(random)` → UUID v4-format string from the PRNG (version and variant bits set), plus an `IdRegistry` that throws on a duplicate (used by 0.2-08b).
   - `names/lists.ts`: hand-written lists of common Syrian male and female given names, family names and Azaz Turkmen/Turkish-format family names, each list with a one-line source note (general naming patterns, no real person). Each variant class tagged: hamza forms (أ/إ/ا), ة/ه ending, ى/ي ending, compound (عبد ال…), article ال.
   - `names/person-name.ts`: `generatePersonName(random, { sex, adult, region })` → `{ given, father, grandfather?, family, motherGiven? }` plus `fullName()`; father/grandfather from the male list, mother from the female list; Azaz region draws Turkmen family names at a set weight. `NAME_VARIANT_SAMPLES`: one fixed name per variant class and a fixed duplicate-name pair, for 0.2-08b to place.
   - `phones.ts`: operator prefix table with source comments (Syria: Syriatel and MTN Syria `+9639x` ranges; Turkey: Turkcell, Vodafone, Türk Telekom `+905xx` ranges); `generatePhone(random, country)` → E.164 with subscriber digits starting `00`; exported `SYRIAN_MOBILE_E164 = /^\+9639\d{8}$/`, `TURKISH_MOBILE_E164 = /^\+905\d{9}$/`; `isSyntheticPhone(e164)` (known prefix + `00` marker).
   - `money.ts`: `type Currency = 'SYP' | 'TRY' | 'USD'`, `interface Money { amountMinor: bigint; currency: Currency }`, `CASH_UNIT_MINOR` (SYP 1000n, TRY 100n, USD 100n), `generatePrice(random, currency, range)` returning whole cash-unit multiples on new-pound scale, `OLD_POUND_THRESHOLD_MINOR` for the BIL-05 check.
   - `index.ts` re-exports; `src/index.ts` adds the public names.
3. **Instructions.** `packages/testing/CLAUDE.md`: synthetic only, never add a real name/clinic/number, never `Math.random`/`Date.now`/`process.env` in `src/synthetic`, use `fork` for new fields.
