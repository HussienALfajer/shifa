# 0.2-04 Flutter via FVM, pub workspace, very_good_analysis, Dart in verify

Status: In review · Tier: T1 (the CI change also gets a `security-reviewer` pass) · Branch: `chore/0.2-04-flutter-toolchain`
Spec: none (foundation tooling; scope is the Phase 0.2 checklist in [roadmap](../roadmap.md), [ADR-0002](../adr/0002-monorepo-pnpm-turborepo.md), [ADR-0012](../adr/0012-flutter-patient-app.md)) · Requirements: —

## Goal
The repository holds Dart/Flutter code next to TypeScript: one pinned Flutter version (FVM), one pub workspace, strict analysis, and `pnpm verify` / CI formatting, analysing and testing Dart exactly like TypeScript. No app yet: `apps/patient_app` is created by the first patient-app slice in Phase A.

## Plan
1. **Flutter pin (FVM).** `.fvmrc` pins the latest stable Flutter 3.47.x patch (confirm on the Flutter releases page at build time; ADR-0012). `.fvm/` stays ignored except `.fvmrc`. The machine has a global Flutter 3.41.2 at `C:\flutter`, which must not be used: install FVM (`dart pub global activate fvm`), `fvm install`, `fvm use`. If `.fvm/flutter_sdk` cannot be linked on Windows (symlinks need Developer Mode), stop and ask the owner to enable it.
2. **Pub workspace.** Root `pubspec.yaml` (`name: shifa_workspace`, `publish_to: none`, Dart SDK constraint from the pinned Flutter, `workspace:` list). Root `analysis_options.yaml`: `include: package:very_good_analysis/analysis_options.yaml`, plus `unawaited_futures` and `discarded_futures` as errors, generated files (`**/*.g.dart`, `**/*.freezed.dart`) excluded. `pubspec.lock` committed at the root (already counted as generated by the PR-size check).
3. **First Dart package** `packages/shifa_testing` (pure Dart, mirrors `@shifa/testing`): `FixedClock` with the same behaviour as the TS one, so the toolchain is proven end to end. `resolution: workspace`, dev deps `test`, `very_good_analysis`.
4. **Turborepo integration.** Each Dart package gets a thin `package.json` (`"private": true`, scripts `typecheck` → `dart analyze --fatal-infos`, `lint` → `dart format --output=none --set-exit-if-changed lib test`, `test` → `dart test` or `flutter test` for Flutter packages), so `--affected`, caching and `--force` work unchanged. `turbo.json` `globalDependencies`: `pubspec.yaml`, `pubspec.lock`, `analysis_options.yaml`, `.fvmrc`. All Dart commands go through `scripts/dart.mjs`, which runs the FVM SDK (`.fvm/flutter_sdk/bin`) and fails with a clear message if it is missing — never the global Flutter.
5. **verify.** New step `pub-get` (`flutter pub get --enforce-lockfile` via `scripts/dart.mjs`) before `typecheck+lint+test`; it runs every time (about 2 s when up to date), which is simpler than path filtering. New step `file-length`: `scripts/check-file-length.mjs` fails any hand-written `.dart` file over 400 lines (same rule ESLint enforces for TS); generated files excluded.
6. **Hooks.** `policy.mjs` `GENERATED` gains `\.g\.dart$`, `\.freezed\.dart$`, `\.mocks\.dart$`. `format-after-edit.mjs` formats `.dart` with the FVM SDK through the same resolver. `.gitattributes`: those patterns `linguist-generated`.
7. **CI.** In the `verify` job, install the Flutter version from `.fvmrc` without a third-party action: download the official Linux archive from Google's release storage, check its SHA-256 against Google's `releases_linux.json` entry (pinned in the workflow, like gitleaks), cache `~/.pub-cache`. FVM itself is not needed in CI; `scripts/dart.mjs` honours `SHIFA_FLUTTER_ROOT` in CI. zizmor must stay clean.
8. **Instructions.** `packages/shifa_testing/CLAUDE.md` is not needed (too small); add `.claude/rules/dart.md` (path-scoped to `**/*.dart`, `pubspec.yaml`): use `scripts/dart.mjs`/`fvm`, never global Flutter; very_good_analysis rules are not silenced per line without a reason comment; models and DTO rules from ADR-0012 come with the app. Update `CLAUDE.md` Commands with the FVM setup line, `docs/architecture/overview.md` if stale, roadmap checklist items (monorepo skeleton, Dart lint).

Tests written first:

- `scripts/test/file-length.test.mjs` — 400-line `.dart` passes, 401 fails, `*.g.dart` of 1,000 lines ignored.
